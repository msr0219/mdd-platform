## 1. 交付范围

交付内容包括 JSON 建模与动态页面、结构与语义校验、Java 模型 CRUD 定制、账号角色与应用授权、行级数据范围、用户逻辑删除、单层 BOM 与生产质量闭环、用料核销及 BOM 工单余料退库、附件、质量图表、整机直通率、服务调用日志及持久化存储。

批量能力保留后端 `batchCreate`、`batchDelete`：同一模型每批 1～200 条，整批成功或回滚，默认复用单条 Java 处理规则。通用前端批量入口、批量更新、模型批量逐条部分成功、专用扫码页面不属于交付范围，不列为待完成开发任务。JSONRPC 请求数组中的请求独立执行，不能用来承诺跨请求整批回滚。
