### 1.1 批量操作边界

| 能力 | 当前执行规则 |
| --- | --- |
| 模型批量接口 | 同一模型的 `batchCreate`、`batchDelete`，参数为 `records` 对象数组，每批 1～200 条；删除每项携带 `id` 和 `version`；整批提交或回滚 |
| Java 定制规则 | 默认批量动作逐条执行单条 `create`、`delete` 处理类；普通接口与默认批量接口复用规则 |
| JSONRPC 请求数组 | 最多 200 个独立请求，逐条鉴权与执行；一个请求失败不回滚其他请求，不能视为模型批量事务 |
| 幂等 | 由显式声明 `idempotencyKey` 的 JSON 服务提供；普通批量接口自身不自动提供幂等回执 |
| 页面与交付范围 | 页面使用单条业务操作；行勾选用于选中状态与计数。通用前端批量入口、批量更新、模型批量逐条部分成功及专用扫码页面不属于交付范围，不列为剩余任务 |
