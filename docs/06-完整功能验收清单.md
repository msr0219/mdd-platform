### 8.2 后端批量接口范围

依据建模指南3.3节，使用有权限的验收账号调用同一模型的 `batchCreate`、`batchDelete`，`params.records` 每批1～200条；删除项包含实际记录的 `id` 和当前 `version`。检查成功时返回 `records` 结果，非法记录、越权或版本冲突时整批回滚。默认删除遵循模型的逻辑删除设置，默认批量动作逐条复用 Java 处理类。

JSONRPC请求数组中的各请求独立执行，不以整个数组作为数据库事务；一个请求失败时其他请求可有独立结果。请求数组结果与同模型批量接口的整批回滚分别验收。模型批量接口自身不提供幂等回执，幂等只验收显式声明 `idempotencyKey` 的业务服务。

页面行选择仅用于选中状态和数量展示。通用前端批量入口、批量更新及逐条部分成功不属于交付范围，不列为未完成验收项。

## 9. 并发、幂等、性能和重启

- 事务/幂等：主要依据自动测试，对显式声明 `idempotencyKey` 的服务检查相同requestId与相同参数只执行一次、改参/跨账号/权限变化拒绝重放，以及后续步骤失败后库存、履历和回执全部回滚。重新打开表单会产生新requestId，不能用“关弹窗后再做一次”验证幂等。
- 并发：自动测试覆盖领料超扣、同装机位置争用、同一领料余额的装机/退库争用；同时观察数据库最终数量和唯一流水，不能只看两个请求是否都返回。
- 重启：完成一轮页面验收后正常停止/启动服务，再核对账号、工单、库存、附件内容和历史；旧整机PRIMARY增量回填不得重复创建或重启用已更换旧件。
- 备份恢复：停机后配套备份data、meta、uploads，在隔离副本恢复并核对同一组记录和文件；当前交付尚未完成正式备份恢复演练。

可选性能专项：

```powershell
.\mvnw.cmd -f .\platform-server\pom.xml '-Dtest=PerformanceAcceptanceTest' '-Dplatform.perf=true' test -B -ntp
```

该测试在独立H2内存库写入100万行，报告为 `platform-server/target/performance-report.txt`，筛选分页P95门槛为1秒。它排除HTTP、登录鉴权、网络，不能代表行级权限、MySQL、完整BOM齐套或多人并发生产容量。
